# Convert-into-DZD-in-French-words
Express the amount in Algerian dinars (DZD) in French words

1-Open a new Excel file.
2-Right-click on the sheet tab and select “View Code”.
3-In the VBA editor, click Insert → Module.
4-Paste the code into the module window.
5-Close the VBA editor and return to Excel.
6-Select a cell in Excel and type: =ConvertToTextDZD("select a cell that contains the amount in DZD").
7-Press Enter.
ENJOY :)
